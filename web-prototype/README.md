# Be - Web Prototype

Prototipo web responsivo de la aplicación Be, diseñado para demostración de UX/UI.

## 🚀 Deploy en Netlify

Este proyecto está listo para deployar en Netlify con un solo click.

### Opción 1: Deploy Manual

1. Arrastra la carpeta `web-prototype` completa a [Netlify Drop](https://app.netlify.com/drop)
2. ¡Listo! Tu sitio estará live inmediatamente

### Opción 2: Deploy desde Git

1. Sube este repositorio a GitHub
2. Conecta Netlify con tu repositorio
3. Configuración de build:
   - **Build command**: (dejar vacío)
   - **Publish directory**: `web-prototype`
   - **Deploy branch**: `main`

## 📂 Estructura

```
web-prototype/
├── index.html         # HTML principal
├── styles.css         # Estilos dark mode gaming
├── particles.js       # Sistema de partículas
├── app.js            # Lógica de la aplicación
├── netlify.toml      # Configuración de Netlify
└── README.md         # Este archivo
```

## 🎮 Características

- ✅ Splash screen con efecto de partículas minimalista

- ✅ Diseño dark mode gaming premium
